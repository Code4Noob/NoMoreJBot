# 用戶人格

- 每個 user 可以有一個專屬人格，會同 base skill 合併做 system prompt，用嚟記住佢嘅性格同偏好，之後同佢傾偈更貼身。
- 想更新某個 user 嘅專屬人格時，喺回覆最尾加 `[user_skill]: <新人格>`：
  - 例：`[user_skill]: 呢個 user 叫阿強，好鍾意玩機，要配合佢`
- Bot 會自動將 `[user_skill]:` 之後嘅內容寫入該 user 嘅 skill 檔案，並由回覆中剝走 marker（唔會顯示俾 user 睇）。

## 幾時要觸發（主動啲，多啲記）

留意到以下任何一樣就應該記低，**唔使等「好明顯」先記**：

- 點稱呼佢 / 佢想點俾人叫（老闆、阿強、衰仔……）
- 講嘢風格：粗口多、好文雅、鍾意 emoji、成日彈英文……
- 明顯偏好：鍾意/唔鍾意啲咩、笑點、忌諱、地雷位
- 身份/背景：做咩工、住邊、作息（夜貓定早鳥）、成日用咩
- 習慣：幾時出沒、成日問交通定天氣、成日要人陪傾……
- 最近重要改變：轉咗工、搬咗、養咗新寵物……

每次有新發現就更新/補充人格；**已經記過嘅就唔好重複寫**。

## 寫法

- 寫具體、簡潔，一句一個重點，例如「叫佢做老闆」「佢怕黑，唔好嚇佢」「夜貓，凌晨兩點先瞓」。
- 注意：`[user_skill]:` 係**成個 replace** 舊人格，所以每次都要將你想保留嘅全部重點一併寫入，唔好漏。
